# S2Q-SEQNN: run logs and analysis scripts

Run logs and analysis scripts for

> **S2Q-SEQNN: Diagnosing Whether a Variational Quantum Circuit Earns Its Place in a Compact Hybrid Classifier.**
> Abdullah, O. Bouhali, S. M. Al-Kuwari, A. F. Salem, M. B. Dastagir. Submitted to *IEEE Transactions on Quantum Engineering*.

Every number, table, and figure in the paper and its supplementary material is generated by a script in `analysis/` from a log in `results/`. Nothing is typed by hand.

## Check the paper's numbers (about one minute, CPU only)

```bash
pip install -r requirements.txt
bash reproduce.sh            # writes every table, figure, and macro file to out/
```

`reproduce.sh` needs no datasets, no checkpoints, no GPU, and no quantum hardware. All numerical macros used in the paper and the supplement are regenerated from `results/` and match the submitted manuscript exactly. Each script stops with an error if an input is incomplete (a missing arm, a wrong seed count, or a failed consistency check).

## The run logs

| Path | Runs | Contents |
|---|---|---|
| `results/all_runs.csv` | 1380 | Main campaign: variants, every control, gate and basis sweeps, sensitivity, learning-rate schedule, baselines; seeds 42 to 51 |
| `results/tqe/nofusion/` | 120 | Four replacement controls with the head fed the branch output alone |
| `results/tqe/scale_*/` | 320 | So2Sat Adaptive at 8 to 15 qubits, four arms (the 10-qubit runs reproduce the main campaign exactly) |
| `results/teacher/` | 50 | Positive control: So2Sat with labels from a fixed circuit teacher, five arms on seeds 42 to 51 (42 to 44 are the pilot runs) |
| `results/teacher_pilot/` | 30 | Three-seed pilot, including the dropped near-initialization teacher |
| `results/tangent/` | 60 | Tangent-space diagnostics of the trained circuits, with singular-value spectra |
| `results/geom/` | 80 + scan | Diagnostics at 8 to 15 qubits and the random-parameter gradient scan to 28 qubits |
| `results/noise/` | 120 | Main-campaign checkpoints evaluated under depolarizing noise |
| `results/hardware/` | 8 jobs | IBM job ID, raw counts, read-out, and summary of every hardware run |

Each row of a run log gives the arm, seed, test accuracy, parameter counts, and the flags of the run. Arms with the same seed share the data split, every initialization, and the mini-batch order, so they are paired.

## Training code

The model, training, and hardware code is available from the corresponding author on reasonable request. The three datasets are public: Overhead-MNIST (Noever and Noever, 2021), SAT-6 (Basu et al., 2015), and So2Sat LCZ42 (Zhu et al., 2020).
